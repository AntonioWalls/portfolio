# 💻 Fabián.dev — Portafolio Personal

Portafolio personal de desarrollo de software (**Fullstack • Mobile • Cloud**) con diseño inspirado en consolas técnicas y estilo Neo-Brutalista.

## 🚀 Stack Tecnológico

- **Frontend:** React 19 + TypeScript
- **Estilos:** Tailwind CSS v4
- **Iconografía:** Lucide React
- **Bundler:** Vite
- **Arquitectura:** Modular por componente (*Feature-based*: vistas, `interfaces` y `constants` desacoplados)

## 🛠️ Cómo correr el proyecto localmente

1. Clonar el repositorio:
   ```bash
   git clone https://github.com/AntonioWalls/portfolio.git
   ```
2. Instalar dependencias:
   ```bash
   npm install
   ```
3. Iniciar el servidor de desarrollo:
   ```bash
   npm run dev
   ```
